# personalPortfolio
This project presents the design and development of a responsive personal portfolio website aimed at showcasing an individual’s technical skills, projects, achievements, and contact details in a professional and accessible manner. The primary goal of the website is to establish an online presence that can serve both as a resume and a central hub for potential employers, collaborators, or clients to learn more about the individual.
# Technologies Used
-HTML:
Markup language used for structuring the website.

-CSS: 
Stylesheet language used for designing and formatting the website.

-JavaScript:
Programming language used for adding interactivity and dynamic features.
